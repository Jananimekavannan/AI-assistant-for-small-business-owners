# Small Business AI Assistant 🤖

This is an AI-powered assistant designed to help small business owners automate tasks, generate content, and improve productivity.

## 🚀 Features
- Generate marketing content
- Answer customer queries
- Provide business insights
- Easy-to-use interface

## 🛠️ Tech Stack
- Python
- Streamlit
- LangChain
- Google Generative AI (Gemini)

## ▶️ How to Run

1. Clone the repo
2. Create virtual environment
3. Install dependencies:
   pip install -r requirements.txt

4. Run the app:
   streamlit run app.py

## 🔐 Environment Variables

Create a `.env` file and add:

GOOGLE_API_KEY=your_api_key_here

## 📌 Project Goal

To help small business owners save time and make better decisions using AI.
